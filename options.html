Show the size of the current tab on the extension icon while you resize the window

Toolbar icon

The number shows while you drag the window and goes away a second after. It counts the side you drag: blue for the width, green for the height. A corner drag shows the width while you move more along X and the height while you move more along Y. The viewport height and the window size show only when their box is on. Hover the icon to see the sizes at any time. With every box off, the icon stays as it was
