# PixelPrism

**PixelPrism** — Chrome-расширение для визуальной проверки адаптивности сайта, инспекции элементов и быстрой передачи правок в разработку. Оно открывает один URL сразу в нескольких независимых viewport'ах, позволяет измерять интерфейс прямо на странице и фиксировать изменения CSS без переключения между DevTools и эмуляторами устройств.

## Возможности

- Одновременный просмотр страницы в пресетах Phone (390 px), Phone L (568 px), Tablet (768 px), Laptop (1024 px) и Desktop (1440 px).
- Добавление собственных viewport'ов: вручную или через готовые пресеты HD, Full HD, QHD и 4K.
- Общий масштаб для всех предпросмотров и независимое изменение их высоты.
- Режим одного viewport'а с изменением ширины без верхнего ограничения; рядом отображается ближайший брейкпоинт и тип устройства.
- Снимок видимой области страницы для любого viewport'а.
- **Inspector**: выбор элемента, его размеры, координаты, CSS-селектор, а также margin, padding и gap контейнера.
- Визуальная правка ширины, высоты, отступов и `row-gap` / `column-gap` выбранного элемента с немедленным результатом в предпросмотре.
- **Layout grid**: монохромная карта раскладки с подсветкой контента, отступов, промежутков и их точных значений.
- **Layers**: дерево DOM-слоёв активного предпросмотра.
- **Comments**: заметки к странице или конкретному элементу с привязкой к viewport'у.
- Передача накопленных правок: скачать Markdown-отчёт или скопировать структурированный контекст через **Copy for Codex**.
- Применение CSS-правок в локальный HTML-файл через системный выбор файла.
- Открытие текущей страницы одним кликом по иконке расширения или через контекстное меню «Открыть в PixelPrism».

## Установка в Chrome

1. Склонируйте репозиторий или скачайте его архив.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика** (*Developer mode*).
4. Нажмите **Загрузить распакованное расширение** (*Load unpacked*).
5. Выберите папку репозитория — ту, где находится `manifest.json`.
6. Откройте нужный сайт и нажмите иконку PixelPrism на панели Chrome.

После внесения изменений в код нажмите кнопку обновления у расширения на странице `chrome://extensions`.

## Как работать

1. Откройте страницу сайта и запустите PixelPrism через иконку расширения. URL текущей вкладки будет подставлен автоматически.
2. Выберите один или несколько размеров устройств на верхней панели. Для произвольного размера используйте кнопку `+`.
3. Изменяйте масштаб кнопками `−` и `+`. Потяните нижнюю границу карточки, чтобы поменять её высоту. В режиме одного viewport'а можно тянуть правую границу, проверяя поведение на промежуточных ширинах.
4. Чтобы изучить элемент, включите **Inspector** (`I`), наведите курсор на элемент и кликните. В правой панели можно изменить доступные CSS-свойства; изменения применяются только к предпросмотру.
5. Включите **Layout grid** в заголовке карточки, чтобы увидеть структуру отступов и контейнеров. Для DOM-навигации используйте **Layers** (`L`).
6. При необходимости добавьте комментарии через **Comments** (`C`). Они попадут в отчёт вместе с выбранным элементом и размером viewport'а.
7. Откройте кнопку передачи изменений в правом нижнем углу:
   - **Download .md** — сохраняет Markdown-отчёт;
   - **Copy for Codex** — копирует структурированный набор правок для передачи в Codex;
   - кнопка сохранения в карточке viewport'а доступна при работе с локальным HTML-файлом и записывает сгенерированный блок CSS в выбранный файл.

Горячие клавиши: `V` — курсор, `I` — инспектор, `C` — комментарии, `L` — слои.

## Локальные файлы

PixelPrism поддерживает адреса вида `file:///…` и абсолютные пути к HTML-файлам. Для этого откройте страницу расширения в `chrome://extensions`, выберите **Подробнее** и включите **Разрешить открывать локальные файлы** (*Allow access to file URLs*).

При первой попытке сохранить правки Chrome попросит выбрать исходный `.html`-файл. Выбор нужен как для `file://`-страниц, так и для страницы, работающей на локальном сервере, например `localhost`.

## Ограничения

Предпросмотр использует `iframe`. Сайты, запрещающие встраивание через `X-Frame-Options` или CSP-директиву `frame-ancestors`, не откроются внутри PixelPrism. Это политика самого сайта; в таком случае откройте страницу в отдельной вкладке.

Визуальные CSS-правки сохраняются в пределах студии, пока вы не экспортируете их, не скопируете для Codex или не примените к выбранному локальному HTML-файлу.

## Разрешения

Расширение запрашивает следующие разрешения Chrome:

- `activeTab`, `tabs` — получить адрес активной вкладки и открыть PixelPrism для неё;
- `contextMenus` — добавить пункт контекстного меню;
- `downloads` — сохранять снимки и Markdown-отчёты;
- `debugger` — создать снимок viewport'а заданного размера;
- доступ к адресам `http`, `https` и `file` — загрузить страницу в предпросмотр.

## Структура проекта

```text
manifest.json       Конфигурация Chrome Extension Manifest V3
background.js       Service worker: запуск студии, снимки и скачивание файлов
studio.html         Интерфейс PixelPrism
studio.js           Логика viewport'ов, инспектора, заметок и экспорта
studio.css          Стили интерфейса студии
inspector.js        Скрипт, выполняемый внутри предпросматриваемых страниц
icons/              Иконки расширения
fonts/              Локальные шрифты интерфейса
```

## Разработка

Проект не требует сборки: это нативное расширение на HTML, CSS и JavaScript. После изменения файлов обновите расширение на `chrome://extensions`, затем перезагрузите вкладку PixelPrism.
